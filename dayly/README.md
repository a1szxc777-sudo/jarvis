# Dayly — Telegram-бот с ИИ-агентом

Личный помощник школьника: расписание, погода, домашка, ИИ-чат (Claude) с инструментами, игры, гороскоп,
викторины, трекер воды и система уровней. Работает через Telegram long polling под systemd (Oracle Cloud Always Free
или любой Ubuntu-сервер).

## Структура папки

```
dayly/
├── bot.py            # логика бота: меню, ИИ-агент, база данных, напоминания
├── content.py        # весь контент: шутки, факты, викторина, гороскоп, тексты ru/kz
├── requirements.txt  # зависимости
├── .env.example      # шаблон настроек (копируется в .env)
├── dayly.service     # systemd-сервис (автозапуск)
├── install.sh        # первая установка на VM
├── update.sh         # обновление после git pull
├── data/             # база SQLite (dayly.db) создаётся здесь
└── .gitignore        # .env и база не попадают в GitHub
```

## Быстрый старт

1. Создай VM Ubuntu в Oracle Cloud (Compute → Instances → Create instance, shape `VM.Standard.A1.Flex`,
   1 OCPU / 6 GB RAM, сохрани SSH-ключ) и подключись: `ssh -i КЛЮЧ ubuntu@PUBLIC_IP`.
2. Залей папку на VM в `/home/ubuntu/dayly` (GitHub private repo + `git clone`, либо `scp -r`).
   Файл `.env` с секретами в GitHub **не** загружай.
3. Установка:
   ```bash
   cd /home/ubuntu/dayly
   bash install.sh
   nano .env
   ```
4. Заполни `.env` (токен от @BotFather, твой Telegram ID из команды /id, ключ ИИ) и запусти:
   ```bash
   sudo systemctl start dayly
   sudo systemctl status dayly      # должно быть active (running)
   sudo journalctl -u dayly -f      # логи в реальном времени
   ```

## ИИ-агент

В `.env` должны быть две строки (без кавычек и пробелов вокруг `=`):

```env
ANTHROPIC_API_KEY=sk-ant-...
AI_MODEL=claude-haiku-4-5-20251001
```

После изменения `.env`: `sudo systemctl restart dayly`. Для более умных ответов можно поставить `AI_MODEL=claude-sonnet-5-5`
(дороже, чем Haiku).

Что умеет ИИ:
- отвечает на любые вопросы текстом и **по фото** (сфоткай задачу, подпись «реши №3» необязательна);
- знает твоё расписание, домашку, дату экзамена, настроение и воду, поэтому отвечает в контексте;
- сам делает дела по твоей просьбе: «добавь алгебру №15 на пятницу», «отметь вторую задачу», «поставь фокус на 30 минут»,
  «запиши 2 стакана воды», «какая погода», «что завтра по расписанию»;
- 4 стиля: 😎 Друг, 🎓 Репетитор, 🧘 Коуч, 🤡 Шутник (кнопка «🤖 ИИ-режим» или /mode);
- под ответом есть кнопки «🧒 Проще» и «🔍 Подробнее».

Если ИИ не отвечает, бот пишет причину: неверный ключ (401), нет денег на аккаунте, неверное имя модели, перегрузка.

## Что ещё внутри

| Раздел | Возможности |
|---|---|
| 📅 День | сводка на сегодня/завтра с праздниками РК, расписание, погода по часам, прогноз на 3 дня, напоминания об уроках |
| 📝 Дела | домашка с датами, фокус-таймер (помодоро), обратный отсчёт до ҰБТ |
| 🎮 Развлечения | анимированные кубики/дартс/баскетбол/футбол/боулинг/слоты, шар судьбы, шутки, загадки, гороскоп, «что выберешь?», челлендж дня, комплименты, /choose, /random |
| 🍀 Жизнь | трекер воды с напоминаниями, дыхание, отдых для глаз, сон, факты, советы, «мне скучно», мотивация |
| 🎓 Учёба | викторина (20 вопросов), английское слово дня, лайфхаки, решение по фото |
| ⭐ Игра | XP за задачи, фокус, настроение, воду, викторину, челленджи; 10 уровней от 🥚 до 👑; серия дней подряд; /profile |
| 🌐 | русский и казахский интерфейс |

Все команды: /help. Дату рождения можно задать через `/bday 25.07` — тогда гороскоп подстроится под знак, а бот
поздравит с днём рождения.

Напоминания о воде приходят в 11:30, 15:30 и 19:30 (если норма 8 стаканов ещё не выпита). Выключить:
⚙️ Настройки → «Напоминания о воде».

## Обновление

```bash
cd /home/ubuntu/dayly
git pull
bash update.sh
```
Если менял только `.env`, хватит `sudo systemctl restart dayly`. Старая база `dayly.db` подхватится сама: новые поля
добавляются автоматически.

## Если что-то не работает

- Логи: `sudo journalctl -u dayly -n 100 --no-pager`. Перед отправкой логов кому-то замени токены на `***`.
- **409 Conflict**: тот же BOT_TOKEN запущен ещё где-то (например, на ПК). Останови второй экземпляр.
- **ИИ молчит**: проверь `ANTHROPIC_API_KEY` в `.env` и баланс на console.anthropic.com.
- Бот отвечает «только для владельца»: впиши свой ID из /id в `OWNER_ID`.

## Важное про Oracle Free

Always Free VM Oracle может забрать, если она простаивает: проверяются CPU, сеть и память за 7 дней. Бот с напоминаниями
и ИИ-чатом создаёт регулярную активность, но 100% гарантии 24/7 бесплатный тариф не даёт. При создании A1 может быть
`Out of host capacity` — попробуй другой Availability Domain или повтори позже.
